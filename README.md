# TradeLoom

B2B trade marketplace for buyers and suppliers. It covers sourcing, catalogs, negotiation, purchase orders, logistics, invoicing, compliance, contracts, and analytics.

## Stack

Django and Django REST Framework. React and TypeScript on the frontend.

## Layout

- `backend/` — Django apps for the API
- `frontend/` — React client source

This copy is application source. It does not include `manage.py`, a Python requirements file, or a frontend `package.json`.
